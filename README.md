# NEXORA – Laptop & Computer Accessories E-Commerce Platform

NEXORA is a modern, full-stack e-commerce web application designed for selling laptops and computer accessories. It provides customers with a smooth shopping experience and administrators with a dedicated dashboard to manage the store efficiently.

The platform includes user authentication, product browsing, shopping cart functionality, order management, product reviews, and an admin dashboard.

## 🚀 Features

### 👤 User Features

- User registration and login
- Secure authentication using JWT and HTTP-only cookies
- Forgot password and reset password functionality
- User profile management
- Profile avatar upload
- Multiple shipping addresses
- Browse and search products
- Product details and reviews
- Add products to shopping cart
- Checkout and place orders
- View order history
- Track order details
- Contact support

### 🛠️ Admin Dashboard

- Admin dashboard with statistics
- Manage products
- Add, edit, and delete products
- Manage product categories
- Manage customer orders
- Manage registered users
- Manage customer contact messages
- View and manage store information

### 🔐 Security Features

- JWT-based authentication
- HTTP-only authentication cookies
- Password hashing
- Protected routes
- Role-based access control
- Token expiration
- Secure password reset functionality
- Environment variable configuration

### 🎨 UI & Experience

- Modern dark-themed interface
- Responsive design
- Reusable React components
- Product cards and detailed product pages
- Custom loading states
- Interactive modals
- Custom scrollbar styling

## 🧰 Tech Stack

### Frontend

- React.js

- React Router DOM
- Tailwind CSS
- JavaScript
- Axios
- Lucide React

### Backend

- Node.js
- Express.js

### Third-Party Services

- Email Service – Welcome emails and password reset emails
